Kerno integration tests are created from the extension in a Python file that contains an endpoint.

Use the Kerno extension, identify the endpoint, then press `Run tests with kerno` above the endpoint definition line.

The docs say Kerno starts indexing the codebase after you write the Kerno key to wake it up.
